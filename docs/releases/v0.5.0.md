# SIMple 0.5.0

Download **SIMple-6.apk** below and open it on Android to install or update SIMple.
Android 8.0 or later is required. Existing users can also check for this release from
**Ajustes → Actualizar SIMple → Buscar actualización**.

## Changes

- One SIM card contains the balance and compact rows for Internet, minutes, messages and bonuses.
- Reading ages, expiry dates and package details expand under **Ver detalles**.
- Notices highlight low resources, known expiry dates and stale readings.
- Recent resource comparisons distinguish observed reductions from purchases, recharges and expiry changes.
- Prominent recharge, plan purchase and balance transfer actions.
- Encrypted saved recipients with favorites, editing, deletion and an optional single-contact picker.
- Transfer review and local history distinguish opening the carrier menu from an outcome confirmed by you.
- Returning from carrier services offers to refresh the original SIM.

## Updating safely

This is a debug-signed compatibility build using the same key as the existing local installations.
It updates those installations in place; do not uninstall or clear app data first.
The app checks the package ID, version code and signing certificate before offering installation.
No PIN is stored and no transfer or purchase is made automatically. Complete those actions in the
carrier menu. No real-money transaction was sent during testing.
